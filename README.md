# 🏙️ City Guide

City Guide is a modern Flutter application designed to help users explore cities with ease. The app provides information about popular tourist attractions, restaurants, hotels, shopping destinations, and other local points of interest in a clean and intuitive interface.

Built with Flutter and Firebase, the application focuses on delivering a fast, responsive, and cross-platform experience across Android, iOS, Web, Windows, macOS, and Linux.

## ✨ Features

- 📍 Explore famous places and attractions
- 🍽️ Discover restaurants and cafés
- 🏨 Find hotels and accommodations
- 🗺️ Easy navigation with categorized listings
- 🔍 Search and browse locations
- ❤️ Save favorite places
- 🔥 Firebase integration
- 📱 Responsive UI for multiple platforms

## 🛠️ Tech Stack

- Flutter
- Dart
- Firebase
- Cloud Functions
- Material Design

## 🎯 Goal

The goal of this project is to provide a simple, modern, and scalable city exploration platform that helps both tourists and local residents discover the best places in a city.
